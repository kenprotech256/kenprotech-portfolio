The Story

Self-taught. Self-driven.
Delivering real results.

"I don't build websites. I build tools that grow businesses — and I've been doing it since I was 14."

I'm Kenneth Kazibwe, a 17-year-old developer from Mutundwe, Kampala. I taught myself to code from YouTube at 14 and haven't stopped since. Today I run KenPro UG — delivering premium web solutions to Ugandan businesses, NGOs, and organizations at prices that actually make sense.

I've shipped KenPro Movies (a streaming platform with its own Android APK), KenSports TV (live sports with push notifications), and GAMEON UG (Uganda's first gaming community) — all real products with real users.
